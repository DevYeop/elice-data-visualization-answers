# CSV로 배우는 Streamlit 차트

가상의 월별 물품 데이터 하나로 차트 네 가지를 살펴봅니다. 수량과 단가는 실제 자료가 아닙니다.

## 시작하기

1. 프로젝트에 Python과 `requirements.txt`의 패키지가 설치되어 있어야 합니다. 폐쇄망에서는 승인된 절차로 미리 준비하세요.
2. 프로젝트 맨 위 폴더의 `start_streamlit.bat`에 실행할 Python 파일을 끌어다 놓습니다. 또는 프로젝트 폴더에서 아래 명령을 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m streamlit run "08_streamlit_csv_차트_실습/01_품목별_막대그래프.py"
```

3. 브라우저가 열리면 `물품_월별_더미.csv`를 파일 올리기 영역에 끌어다 놓습니다.
4. 다른 예제는 실행 중인 터미널에서 `Ctrl+C`로 종료한 뒤 해당 Python 파일을 같은 방법으로 실행합니다. 각 예제에서 CSV를 다시 올려야 합니다.

## 실습 순서

1. `01_품목별_막대그래프.py`: 품목별 수량 비교
2. `02_월별_선그래프.py`: 월별 수량 변화
3. `03_품목별_원형차트.py`: 품목별 수량 비율
4. `04_수량과_단가_산점도.py`: 수량과 단가의 관계

CSV에는 `월`, `품목`, `수량`, `단가` 열이 필요합니다. 이 단계에서는 데이터를 조회하고 차트로 표시합니다.

## 05. 월별 비품 현황 편집

각자 PC에서 최신 CSV를 올려 수량을 수정하고, 내려받은 수정본을 팀에 전달하는 예제입니다.

저장소 최상위 폴더에서 실행합니다. 아래 명령은 Windows PowerShell 기준입니다.

```powershell
.\.venv\Scripts\python.exe -m streamlit run '08_streamlit_csv_차트_실습/05_비품_현황_편집.py'
```

1. 브라우저에서 같은 폴더의 `비품현황_v01.csv`를 올립니다. 11월 모니터는 보유 12대, 기준 15대입니다.
2. 편집할 월에서 11월을 선택합니다. 표에서 모니터의 보유수량을 15로 수정하고 `Enter`를 누르면 차트와 부족 수량이 갱신됩니다.
3. 월을 바꿔도 이 세션의 수정 내용은 유지됩니다. **수정본 CSV 내려받기**를 누르면 모든 월의 데이터가 `비품현황_v02.csv`에 담깁니다.
4. 담당자가 승인된 사내 경로로 수정본을 전달합니다. 받은 사람은 자기 앱에 같은 파일을 올려 확인합니다. 다음 수정도 배포된 최신본에서 시작하세요.

CSV는 UTF-8로 저장합니다. 열은 `기준월`, `품목코드`, `품목명`, `보유수량`, `기준수량`입니다. 같은 기준월에 품목코드는 한 번만 나오며, 수량은 0 이상의 정수입니다. 내려받기 전 편집 내용은 현재 브라우저 세션에 있습니다.
